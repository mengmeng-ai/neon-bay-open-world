Neon Bay is an original 2D top-down open-world crime game: explore a neon city on foot and by car, steal cars, outrun the police as your wanted level rises, and complete three story missions for fixer Marla Vane. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Controls: WASD/arrows move/drive, Shift sprint, E steal/exit car, F punch, H horn, Space brake, P pause (auto-saves), M mute.
